About

What this project is

Built collaboratively with Mohamed Ben Ali, this car demonstrates how mecanum wheels enable smooth 360° omnidirectional movement — sliding sideways, cutting diagonals, or spinning on the spot without ever changing which way the chassis is facing. It's controlled wirelessly over WiFi through a browser-based interface, combining embedded systems, robotics, and wireless communication into one hands-on platform for learning and experimentation.

Objectives

  • Design a 4-wheel mecanum chassis for full omnidirectional motion
  • Implement independent PWM control for each motor using the ESP32
  • Develop an ESP32 web server for real-time wireless control
  • Create a responsive, browser-based control interface

Build Process

Electronics & wiring

Two H-bridge drivers split the work: one controls both left-side motors, the other both right-side motors. Each motor gets two digital pins for direction and a PWM signal for speed — a setup that keeps current handling stable and wiring simple for a four-motor mecanum drivetrain.

Mechanics

How mecanum wheels work

Each wheel has small rollers around its rim, angled at 45° and spinning freely on their own. When the wheel turns, those angled rollers split the force in two directions at once — partly forward, partly sideways. Mount four wheels with their rollers angled opposite to their diagonal partner, and spinning each one at a different speed and direction lets the whole chassis move any way at all — forward, sideways, diagonal, or spinning in place — with zero steering mechanism.

Interface

Driving the robot

No app to install — the ESP32 hosts its own control page. It runs its own WiFi access point (MecanumCar), and any phone or laptop that joins it can open the controller straight from a browser.

Speed — live PWM via /speed endpoint
  1. Power on the robot — the ESP32 boots and creates the MecanumCar WiFi network
  2. Connect to it from your phone or laptop (password: 12345678)
  3. Open a browser and go to http://192.168.4.1
  4. Press and hold any direction button to drive — release to stop
