Overview

A fully-featured streaming platform built from scratch

Raksha started as an exercise in understanding how complex applications are structured — role-based access, secure database interactions, and rich UI. Inspired by Netflix, the goal was to replicate the feel of a real streaming product while learning every layer of the stack.

The name Raksha (रक्षा) means "protection" in Sanskrit — a nod to the emphasis on secure authentication and data safety at every layer of the application.

Designed and implemented entirely solo, from database schema design and JDBC connection management, to the JavaFX scene graph, CSS styling, and FXML layouts.

🔐

Secure by Design

Password-based authentication with hashed credentials stored in MySQL. Session management controls access to all protected routes.

🎭

Dual Role System

Two fully separate interfaces: a polished viewer experience for users and a powerful content management dashboard for admins.

🖥️

Rich Desktop UI

Built with JavaFX and styled with CSS — responsive layouts, smooth scene transitions, and a dark Netflix-inspired visual language.

🗄️

Full Database Integration

Relational schema in MySQL handling users, roles, movies, series, and watch history — all accessed via JDBC with prepared statements.

Capabilities

Feature Breakdown

01
🔑
Role-Based Authentication
Login system with two roles: standard User and Admin. Role is stored in the database and determines which interface is loaded on sign-in. Sessions are managed in memory throughout the application lifecycle.
02
🎬
Content Browsing & Discovery
Users can browse a full library of movies and series. Content is loaded dynamically from the MySQL database via JDBC and presented in a horizontally scrollable row layout — similar to Netflix's core browsing experience.
03
▶️
In-App Video Streaming
Integrated JavaFX MediaPlayer for in-application video playback. Custom player controls include play/pause, seek bar, volume, and fullscreen — all implemented from scratch.
04
🛠️
Admin Content Management
Admins access a separate dashboard to add, edit, and delete movies and series entries. All changes are persisted to the database immediately via JDBC and reflected in the user-facing content library.
05
👥
User Management
Admin panel includes user management: view registered accounts, change user roles between standard and admin, or deactivate accounts. All operations update the MySQL user table in real time.
06
🎨
Dark Netflix-Inspired UI
JavaFX styled entirely with custom CSS — dark colour palette, smooth scene transitions, hover states, and a layout hierarchy modelled after real streaming platforms for a polished, professional feel.

Process

Challenges &
Solutions

01

Role-Based Scene Management

JavaFX doesn't have a built-in routing system. Loading the correct interface after login based on role required careful architecture to avoid duplication and maintain clean scene transitions.

Solution

Implemented a central SceneManager utility class that maps roles to FXML roots. On successful login, the controller queries the user's role from the DB, then delegates to SceneManager to load and swap the correct scene on the primary Stage.

02

Secure Password Storage

Storing plain-text passwords in MySQL is a critical vulnerability. Needed a way to securely hash and verify credentials without adding large external dependencies.

Solution

Used Java's built-in MessageDigest with SHA-256 to hash passwords before storage. On login, the entered password is hashed and compared to the stored hash — no plain text ever touches the database.

03

Dynamic Content Loading

Populating the UI with database content at runtime — especially horizontal card rows — without blocking the UI thread was a core challenge with JavaFX's single-threaded model.

Solution

Offloaded database queries to JavaFX Task objects running on background threads, then used Platform.runLater() to safely update UI components once data was ready — keeping the interface responsive throughout.
