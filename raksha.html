Raksha — Desktop Streaming App
A Netflix-inspired desktop application built with JavaFX and MySQL. It includes authentication, admin dashboard, and role-based access control.

📌 Project Overview

Raksha is a desktop streaming platform inspired by Netflix. It allows users to browse and stream content while admins manage movies, users, and system data.

⚙️ Technologies Used

  • Java
  • JavaFX (UI)
  • MySQL Database
  • JDBC

🧠 Features

  • User & Admin authentication
  • Role-based access system
  • Video browsing interface
  • Admin dashboard for content management
  • Secure database connection
